Chrome extension

Foothold

Find hiring posts in the LinkedIn tab you are already logged into, score them, and save Gmail drafts. Foothold does not send anything.

Download the extension

Load the unpacked extension

  1. 01Unzip the file. Inside is a folder named extension.
  2. 02In Chrome, open chrome://extensions and turn on Developer mode.
  3. 03Click Load unpacked and choose that extension folder.
  4. 04Pin Foothold and stay logged into LinkedIn. Chrome 114 or newer.

You bring your own OpenAI key. Connecting Gmail is optional. Automated use of LinkedIn is against LinkedIn's terms, so run it sparingly.
